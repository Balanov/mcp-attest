Nine checks

IDRuleFails when
C1default-denyan unset allowlist means "allow everything"
C2list/call paritya tool hidden from tools/list is still callable by name
C3narrowing onlya request widens a client's grant
C4credential separationthe client token is replayed upstream
C5fail closeda call is allowed because the check errored
C6enforcement paritythe policy denies it, the gateway allowed it
C7shadow MCPa server is reachable outside the gateway
C8receipt chainallowed calls left no verifiable receipt
C9description integritya tool definition changed after approval

Why it exists

agentgateway, own evaluation · October 2026

"One argument-conditioned policy was reported as accepted and still did not enforce what it said… turning a policy on is not the end of the job: send real calls and check."
State of MCP Security 2026

"Gateways only protect the servers they route. An agent calling an MCP server outside the gateway is invisible."
CISA · MCP security design considerations

"Without these traceable audit logs, incident response and accountability become significantly difficult, especially in multi-tenant environments."

Use it in CI

1
Emit a trace
Newline-delimited JSON from any proxy, harness or pipeline step. Nothing to instrument deeply.
2
Write the policy
attest init scaffolds one. Default deny, per-client allowlists, conditions on arguments.
3
Gate the build
The action fails on critical or high findings, so "the policy is enforced" becomes something the pipeline proves.
